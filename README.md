### 🔭 What I'm up to

I'm currently diving into **offensive security and networking**, building out a home lab and documenting the journey on my [blog](https://clswhre.github.io/). Recent adventures include:

- 🛡️ Building an isolated **Jump Box homelab** (Debian + KVM) to safely attack a Metasploitable 2 VM
- 🎯 Practicing recon with **Nmap**, traffic analysis with **Wireshark**, and manual exploitation over blind tool-running
- 🧩 Solving **crackmes** with static analysis in **Ghidra** and dynamic analysis with **ltrace** — including writing my own keygen in C
- 🌐 Self-hosting **AdGuard Home** as a DNS/ad-blocking layer on my home network
- 🎓 Completed a university **Summer Cyber School** covering Linux, TCP/IP, CIDR, NAT/DHCP, and AAA

### 🧠 Currently learning
Reverse engineering, network protocols, and Linux internals — with an eye on joining my university's CTF team.
